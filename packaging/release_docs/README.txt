PIXLER - DESKTOP PALLAS'S CAT

A little pixelated neighbor: wanders around, sleeps, grooms itself,
sharpens its claws, rolls in the sand, and sometimes hunts your cursor.


HOW TO RUN

1. Fully extract the ZIP archive to a folder of your choice.
2. Run DesktopPet.exe.

This build is intended for 64-bit Windows.
The _internal folder must remain next to DesktopPet.exe — it contains
the animations and application components. Do not run the EXE directly from the archive.

WALK ON WINDOWS

Right-click Pixler and toggle "Walk on windows" to let it explore the tops
of suitable windows. This is off by default and your choice is saved.
Turning it off brings Pixler back down to the desktop.
