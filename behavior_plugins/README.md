Скопируйте сюда один `.py`-файл сценария и перезапустите приложение.
Пример: `examples/stretch.py`. Полный контракт описан в корневом `README.md`.

В собранной версии создайте `behavior_plugins` рядом с `DesktopPet.exe`.
Скрипты исполняются как обычный Python-код приложения; устанавливайте свои
скрипты или скрипты из доверенных источников.
